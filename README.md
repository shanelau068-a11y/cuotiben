给二年级小朋友用的古诗词错题练习小 App，手机打开就能用。

## 怎么用

- **开始练习**：按顺序做一遍错题，做完出分
- **随机抽题练习**：打乱顺序再来一轮
- **复习讲解**：直接看每道题的正确答案和讲解

答题后会立刻告诉你对错，并显示讲解。成绩会记在手机浏览器里（历史最佳）。

## 每天加新错题

把每天的错题按格式追加到 `questions.js` 末尾即可（格式见文件头注释），提交后网页自动更新。

## 本地预览

直接用浏览器打开 `index.html`，或 `python3 -m http.server` 后访问。
